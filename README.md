# Jeval v2

Jeval v2 tests one hypothesis: does a trained embedding prediction residual detect harmful information loss in a proposed conversational-memory compression better than cosine distance?

The former implementation is preserved in [`jeval_v1/`](jeval_v1/README.md). Its claims and results are not v2 results.

See [`jeval_v2/README.md`](jeval_v2/README.md) for the data contract, commands, and evaluation boundaries.

This branch is a research scaffold. No benchmark result is claimed.
